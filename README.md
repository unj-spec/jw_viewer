# jw_viewer — 소설 뷰어

폰(안드로이드) 앱과 PC 프로그램으로 소설 txt 파일을 읽는 뷰어입니다.

- **PC의 소설**: PC에서 쓰는 중인 소설을 와이파이로 불러와 읽습니다. PC에서 고쳐 저장하면 폰 화면이 몇 초 안에 **자동으로 새로고침**됩니다.
- **폰의 소설**: 폰에 저장된 txt 파일을 바로 엽니다. PC가 꺼져 있어도 됩니다.

## 처음 한 번: 앱 설치

1. PC에서 `start.bat` 를 더블클릭합니다. 창에 이런 줄이 나옵니다.
   ```
   같은 와이파이: 192.168.0.10:8080   (앱에 이 주소를 입력)
     앱 설치 파일: http://192.168.0.10:8080/app
   ```
   처음 실행할 때 Windows 방화벽 창이 뜨면 **개인 네트워크 허용**을 누르세요.
2. 폰을 PC와 같은 와이파이에 연결하고, 폰 크롬에서 `앱 설치 파일` 주소를 열어 받습니다.
   (USB나 카카오톡 등으로 `NovelViewer\소설뷰어.apk` 를 폰에 옮겨도 됩니다.)
3. 받은 파일을 눌러 설치합니다. "출처를 알 수 없는 앱" 경고가 나오면 **이 출처 허용**을 켜고,
   Play 프로텍트 경고가 나오면 **무시하고 설치**를 누릅니다(직접 만든 앱이라 나오는 경고입니다).
4. 앱을 열면 PC 주소를 묻습니다. `192.168.0.10:8080` 을 입력하고 **연결**.
   PC 없이 폰 파일만 볼 거면 **PC 없이 폰 파일만 보기**를 누릅니다.

## PC 소설 폴더 등록 (처음 한 번)

폰에서 볼 PC 폴더를 정해 둡니다. 정한 폴더 안의 txt 파일만 폰에서 보입니다.

- `폴더추가.bat` 를 더블클릭 → 소설 폴더 선택 → 끝 (여러 개 추가 가능)
- 등록한 폴더는 `folders.txt` 에 한 줄씩 적혀 있습니다. 빼려면 그 줄을 지우면 됩니다.
- 아무 폴더도 등록하지 않으면 `NovelViewer\novels` 폴더를 씁니다.

## 소설 열기

앱에서 화면 가운데를 눌러 메뉴를 띄우고 **☰** 를 누릅니다.

| 탭 | 하는 일 |
|---|---|
| **최근** | 전에 읽은 소설 목록 (PC·폰 모두). 누르면 읽던 곳부터 이어서 |
| **📁 PC** | PC에 등록한 폴더를 둘러보고 txt 파일을 고름 (PC에서 `start.bat` 이 켜져 있어야 함) |
| **☁ 깃허브** | GitHub 저장소의 txt 를 읽음. PC가 꺼져 있어도, 밖에서도 됨 (아래 참고) |
| **📱 폰** | 폰의 파일 선택 창이 열림. 다운로드·내 파일·구글 드라이브 등의 txt 를 고름 |

## GitHub 에서 읽기 (처음 한 번 설정)

1. GitHub 에서 읽기 전용 토큰을 만듭니다.
   https://github.com/settings/personal-access-tokens/new →
   Repository access: **Only select repositories** 에서 소설 저장소 선택 →
   Permissions → Repository permissions → **Contents: Read-only** → Generate token
2. 앱에서 ☰ → **☁ 깃허브** → 저장소 주소와 토큰을 넣고 **저장하고 열기**.
   저장소 주소는 폴더 주소를 그대로 붙여 넣어도 됩니다(예: `https://github.com/아이디/저장소/tree/main/폴더`). 그 폴더부터 보입니다.

- 토큰은 앱 안에만 저장되고 다른 곳으로 보내지 않습니다(GitHub 에만 씀).
- PC에서 고친 뒤 **push** 해야 폰에 보입니다. 읽는 중에는 30초마다 바뀌었는지 확인해서 자동으로 새로고침합니다.

## 읽기 기능

- 앱을 켜면 "마지막으로 접속한 PC에 연결해서 이어 읽을까요?" 를 묻습니다. **이어 읽기** = 마지막 소설을 읽던 페이지부터, **목록 보기** = 다른 소설 고르기. PC가 꺼져 있으면 안내가 뜨고, PC를 켠 뒤 **다시 시도**를 누르면 됩니다
- 읽는 동안에는 메뉴와 폰의 위아래 막대가 숨겨지고 글만 보임. **화면 가운데를 누르면 메뉴가 나옴**
- 넘기기 방식 (메뉴 **가** → 넘기기 방식)
  - **페이지 (터치)**: 한 페이지씩 바로 넘어감. 화면 위쪽 1/3 = 이전, 아래쪽 1/3 = 다음, 밀어서 넘기기도 됨
  - **스크롤 (위아래)**: 손가락으로 끌어서 이어 읽기
- **다음 화 이어 읽기**: PC 소설의 마지막 페이지에서 한 번 더 넘기면 "다음 화로 넘어갈까요?" 를 묻고, **다음 화**를 누르면 같은 폴더의 다음 txt(파일 이름 번호 순: 1, 2, … 10)를 첫 페이지부터 엽니다. 첫 페이지에서 앞으로 넘기면 이전 화(마지막 페이지부터)로 갈지 묻습니다
- **페이지 이동 바**: 메뉴를 띄우면 화면 아래에 바가 나옴. 끌면 그 페이지로 바로 감(오른쪽에 "12 / 340 쪽", 스크롤 방식에서는 %)
- **볼륨 키**로 넘기기(− = 다음, + = 이전), 설정에서 끌 수 있음
- **테마 10가지**: 밝게·종이·연두·하늘·분홍·회색·저녁·어둡게·남색·검정
- 🔖 책갈피: 지금 위치 저장, 눌러서 이동, 삭제
- 글자 크기, 줄간격, 본문 폭 조절 · 읽는 동안 화면 꺼짐 방지
- 보기 전용: 길게 눌러도 글자 선택 안 됨, 파일 수정 기능 없음
- UTF-8, UTF-16, CP949(메모장 ANSI) 한글 인코딩 자동 인식

PC 브라우저로 `http://localhost:8080` 을 열어도 PC 소설을 같은 화면으로 볼 수 있습니다.

## PC 버전 (jw_viewer_pc_setup.exe)

PC에서 쓰는 창 프로그램입니다. 서버나 브라우저 없이 **PC 폴더의 txt** 와 **GitHub 저장소** 를 직접 읽습니다.

1. [최신 릴리스](https://github.com/unj-spec/jw_viewer/releases/latest)에서 `jw_viewer_pc_setup.exe` 를 받아 실행 → 바탕화면과 시작 메뉴에 **소설 뷰어** 가 생깁니다(관리자 권한 필요 없음).
2. ☰ → **📁 PC** → **＋ 폴더 추가** 로 소설 폴더를 고릅니다. 빼려면 폴더를 오른쪽 클릭 → 목록에서 빼기(폴더 자체는 지우지 않음).
3. ☰ → **☁ 깃허브** 에서 폰과 같은 방법으로 저장소 주소와 토큰을 넣으면 GitHub 소설도 읽습니다.

- 페이지 넘기기: 화면 위·아래 1/3 클릭, 마우스 휠, 방향키, PageUp/PageDown, 스페이스. 가운데 클릭 = 메뉴 숨기기/보이기(글 위치는 그대로)
- 아래 바: **◀ 이전 장 / 다음 장 ▶**, 페이지 이동 바
- 창 크기에 맞춰 줄을 다시 나누고 양쪽 끝을 맞춥니다. 여백은 **가 → 양옆 여백 / 위아래 여백** 또는 `[` `]` 키
- 설정·책갈피·GitHub 연결은 `%APPDATA%\NovelViewer\pc.json` 에 저장됩니다(GitHub 토큰은 이 PC에서만 풀 수 있게 암호화). 지우기: 설정 → 앱 → **소설 뷰어** 제거.
- 다시 만들기: `powershell -ExecutionPolicy Bypass -File pc\build.ps1` (Windows 기본 .NET Framework 4 와 Inno Setup 6 만 있으면 됨)

## 자동 업데이트

PC 프로그램과 폰 앱 모두, 켤 때 이 저장소의 [최신 릴리스](https://github.com/unj-spec/jw_viewer/releases/latest)를 확인합니다.
새 버전이 있으면 "업데이트할까요?" 를 묻고, **업데이트** 를 누르면

- **PC**: 설치 파일을 받아 조용히 설치한 뒤 다시 켜집니다.
- **폰**: APK 를 받은 뒤 설치 화면이 뜹니다. 처음 한 번은 **이 출처 허용** 을 켜야 합니다.

직접 확인하려면 PC 는 **가 → 업데이트 확인**, 폰은 **가 → 업데이트 확인**.

### 새 버전 내보내기 (만드는 사람용)

1. 맨 위 `VERSION` 파일의 숫자를 올립니다(예: `1.2.0` → `1.2.1`). PC·폰 버전이 모두 이 값을 씁니다.
2. 고친 내용을 커밋하고 아래를 실행합니다. PC 설치 파일과 APK 를 빌드해 GitHub 릴리스 `v1.2.1` 로 올립니다.
   ```
   powershell -ExecutionPolicy Bypass -File release.ps1 "바뀐 점 한 줄"
   ```
3. 그다음 켜는 PC·폰 앱이 새 버전을 알려 줍니다.
## 보안 메모

`start.bat` 창이 열려 있는 동안에는, 같은 와이파이에 연결된 기기가 **등록한 폴더 안의 txt 파일을 읽을 수 있습니다**.
다른 폴더나 다른 종류의 파일은 내주지 않고, 파일을 고치거나 지우는 기능도 없습니다.
카페 같은 공용 와이파이에서는 켜 두지 마세요.

## 앱 다시 빌드하기 (화면이나 앱을 고쳤을 때)

```
powershell -ExecutionPolicy Bypass -File android\build.ps1
```

- 뷰어 화면(`index.html`)도 앱 안에 들어가므로, 화면을 고치면 다시 빌드해서 설치해야 합니다.
- 필요한 것: JDK 17, 안드로이드 SDK(`%LOCALAPPDATA%\Android\Sdk` 에 build-tools 35.0.0, platforms android-35).
- 서명 키 `android\release.keystore` 는 저장소에 올리지 않습니다(.gitignore). 지우거나 잃어버리지 말고 따로 백업하세요. 같은 키로 서명해야 폰의 앱을 덮어서 업데이트할 수 있습니다.
